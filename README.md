# Memory Game

Браузерная игра на память в космической тематике. Игрок открывает карточки и ищет одинаковые изображения. Цель — найти все 8 пар за минимальное количество ходов.

## Описание программы

Проект представляет собой одностраничное веб-приложение, реализованное на JavaScript без использования фреймворков и библиотек.

Игровое поле состоит из 16 карточек, которые образуют 8 пар. В качестве изображений используются обложки космических и фантастических вселенных:

- Eve Online
- Star Wars
- Firefly
- Battlestar Galactica
- Mass Effect
- Star Trek
- StarCraft
- Warhammer 40 000

Карточки перемешиваются случайным образом при запуске игры и при нажатии кнопки «Новая игра».

### Основные возможности

- Случайное перемешивание карточек.
- Переворачивание карточек по клику.
- Сравнение двух открытых карточек.
- Блокировка совпавших пар.
- Подсчёт количества ходов.
- Подсчёт открытых пар.
- Кнопка «Новая игра» для сброса и перезапуска.
- Кнопка «Таблица лидеров».

### Технологии

- HTML5
- CSS3
- JavaScript

## Правила игры

1. В начале игры все карточки закрыты.
2. Игрок кликает по карточке, чтобы перевернуть её.
3. За один ход можно открыть две карточки.
4. Если на открытых карточках одинаковые изображения:
   - карточки остаются открытыми;
   - пара считается найденной;
   - счётчик открытых пар увеличивается.
5. Если изображения разные:
   - карточки через 1,5 секунды переворачиваются обратно;
   - счётчик ходов увеличивается.
6. Игра продолжается до тех пор, пока не будут найдены все 8 пар.
7. Когда счётчик показывает «Открыто пар 8 из 8», игра завершена.
8. Чтобы начать заново, нажмите кнопку «Новая игра».

## Управление

- **Клик по карточке** — перевернуть карточку.
- **Новая игра** — перемешать карточки и сбросить счётчики.
- **Таблица лидеров** — показывает таблицу лидеров.
